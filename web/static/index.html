WHY GEOTILEIFY

One file. Infinite zoom. Zero tile server.

Everything is computed once with Tylertoo and DuckDB Spatial, stored on S3-compatible object storage, and streamed by byte range.

Convert in seconds.

Send a GeoJSON, FlatGeobuf, GeoParquet, or zipped Shapefile to /generate and get back a single .pmtiles archive with a signed download URL.

TYLERTOO · DUCKDB SPATIAL

Stream by byte range.

Clients fetch only the tiles they need through /tiles/:id. Plug the URL straight into MapLibre GL JS via pmtiles://.

HTTP RANGE · MAPLIBRE READY

Expire by design.

Every tile carries a 24-hour TTL. Expired archives are swept automatically every 15 minutes — no stale data, no manual cleanup.

24H TTL · AUTO SWEEP

API REFERENCE

Four endpoints. That is the whole surface.

Integrate from any client — browser extension, notebook, or edge worker. Uploads are multipart/form-data under the file field.

GET

/health

Service status probe. Used by the badge in the navigation bar above.

POST

/generate

Accepts one geospatial file, returns id, download_url, and expires_at.

GET

/download/:id

Redirects to a 5-minute signed URL that forces a file download.

GET

/tiles/:id

Redirects to a 5-minute signed URL with range support for live map streaming.
