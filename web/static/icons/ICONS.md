Place your downloaded Lucide SVGs in this folder (24x24, stroke=currentColor).

Required files (referenced from web/static/index.html):
  favicon.svg      <- 4-tile brand mark (same mark as header/footer)
  activity.svg     <- lucide "activity" (nav pill, /health endpoint, footer)
  arrow-right.svg  <- lucide "arrow-right" (announce bar link)
  arrow-up.svg     <- lucide "arrow-up" (footer back-to-top link)
  menu.svg         <- lucide "menu" (mobile hamburger button)
  download.svg     <- lucide "download" (nav CTA + primary hero CTA)
  book-open.svg    <- lucide "book-open" (secondary CTA)
  zap.svg          <- lucide "zap" (feature card + /generate endpoint)
  layers.svg       <- lucide "layers" (feature card)
  clock-3.svg      <- lucide "clock-3" (feature card)
  database.svg     <- lucide "database" (/download endpoint)
  earth.svg        <- lucide "earth" (/tiles endpoint)

Download from https://lucide.dev/icons/<name> (SVG tab).
Served by the backend at /static/icons/<file> with Content-Type image/svg+xml.
The favicon uses /static/icons/favicon.svg (4-tile brand mark).
